# 🌐 CARA CEPAT & GRATIS HOSTING KEBIJAKAN PRIVASI (PRIVACY POLICY URL)

Google Play Console mewajibkan Anda memasukkan tautan (URL) Kebijakan Privasi yang bisa diakses secara publik oleh siapa saja lewat internet.

Pilih salah satu cara termudah berikut:

---

### OPSI 1: GITHUB PAGES (Sangat Direkomendasikan jika punya akun GitHub)
1. Buat repository baru di GitHub bernama `osis-privacy-policy` (atau gunakan repository aplikasi ini).
2. Upload file `privacy_policy.html` dan beri nama `index.html`.
3. Buka repository di GitHub -> Masuk menu **Settings** -> **Pages**.
4. Pada **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
5. Dalam 1 menit, Anda akan mendapatkan URL publik seperti:
   `https://username.github.io/osis-privacy-policy/`
6. Masukkan URL tersebut ke Google Play Console!

---

### OPSI 2: NETLIFY DROP (Tanpa Koding, Langsung Jadi dalam 10 Detik)
1. Buka https://app.netlify.com/drop
2. Drag and drop folder `06_PRIVASI_DAN_SYARAT` (yang berisi `privacy_policy.html` di-rename jadi `index.html`) ke halaman tersebut.
3. Anda langsung mendapatkan URL live gratis, contoh:
   `https://osis-management-policy.netlify.app`

---

### OPSI 3: GOOGLE SITES ATAU BLOGGER ATAU NOTION
1. Buka https://sites.google.com atau https://www.blogger.com atau Notion.
2. Buat halaman baru, salin seluruh teks dari file `PRIVACY_POLICY.md`.
3. Publikasikan dan salin link publiknya ke Google Play Console.
